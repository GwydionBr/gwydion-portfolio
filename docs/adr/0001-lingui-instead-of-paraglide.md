# Lingui instead of Paraglide for interface text

The rebuild replaces Paraglide with Lingui, set up the way Self-Engine sets it up: PO catalogs, English as the Base language, and the English text itself as the message id. Paraglide worked well here. We still switch, so that both of Gwydion's codebases translate in one way, with one set of conventions and tooling, and so knowledge and code patterns carry over between them.
