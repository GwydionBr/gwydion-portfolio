## The brief

Endstation Tattoo is a studio with several artists in Ottobeuren. Its old website ran on WordPress and Elementor. The studio found it hard to change, and booking requests arrived as loose emails. I rebuilt it so the studio can edit everything itself and every booking request ends up in one place where the team can work through it.

## A site the studio edits itself

The site shows the artists and their work, a tattoo gallery, FAQ, aftercare, a shop and a guided booking form. Every page is content in Sanity. The studio edits it in its own hosted Studio, and a published change goes live without a deploy. Editors can preview drafts on the real site and click any part of the page to edit it, using Sanity's Presentation tool. Sanity TypeGen types the GROQ queries, so a schema change that breaks a page fails the build before it reaches the live site.

To keep the search rankings after leaving WordPress, I set up 301 redirects for every old URL that still matters, `410 Gone` for the WordPress leftovers (`wp-admin`, `wp-content`, tag pages), a sitemap and structured data for the studio.

## Booking requests

The booking form asks for what an artist needs to quote a tattoo: the artist (picked from Sanity), placement, size, a deposit option and reference images, which the browser shrinks to 2 MB before upload. One Zod schema validates the form in the browser and on the server.

At first, each request went to Nextcloud as a PDF. That stopped working once requests needed a status, someone to claim them, handover between artists and protection against duplicates. I replaced it with my own request portal on Supabase.

- A request counts as received only once it is saved. A retry reuses the same submission ID, so a flaky connection never creates a duplicate.
- Artists get at most one summary email a day, with no customer data in it.
- The portal deletes requests six months after they are closed.
- The form data stays in the EU, because the site runs in Vercel's Frankfurt region.

## One codebase, several studios

Endstation is the main site in a small monorepo that also runs websites for solo tattoo artists. The sites share packages for the artist pages, the Sanity Studio and the preview. Each site still has its own Sanity project, Vercel project and credentials, because each one belongs to a different owner.
